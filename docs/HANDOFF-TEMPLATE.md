# Task handoff

## Goal

What outcome did the user request?

## Current state

What exists now? Which files changed? Use paths appropriate for the receiving agent; do not include unrelated private paths in a public example.

## Decisions to preserve

What must remain true, and why?

## Evidence

Which checks ran, and what did they show? Which checks were not run?

## Next action

What is the next concrete step? How should its result be verified?

## Ownership and limits

Who owns the relevant files? What actions still need separate authorization?

## Open questions

What is unknown? What failed? Do not turn an assumption into a fact.
