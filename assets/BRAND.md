# HustleMemory

**Shared memory for your AI agents.**

The mark uses two separated sides of an H and a central transfer block. Each side represents an agent; the block represents context passed between them.

## Palette

| Role | Color |
|---|---|
| Fire orange | `#FF5C00` |
| Warm charcoal | `#0B0A09` |
| Cream | `#F5F2EC` |
| Warm highlight | `#FFE9C2` |

Use the SVG monogram for small icons. The banner includes readable text and an accessible description. The wordmark uses system sans-serif fallbacks so the repository does not require external font downloads.

The brand follows a dark editorial style with a single orange accent. Keep the monogram flat and give it generous clear space. Avoid brain clip art, vendor logos, gradients, and artificial glow.

`hustlememory-concept.png` is the AI-generated visual concept. The SVG files are the editable geometric production assets. The project name has not undergone trademark clearance.
